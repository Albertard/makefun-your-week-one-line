# Your Week in One Line

A program that writes exactly one line to `/output/entry.txt` — a single line that sums up my week: the win, the fail, the chaos, all of it. Built for the make.fun competition **"Your Week in One Line"** (`u-boge-your-week-in-one-line-d1c14ced`).

## The line

> Built 25 bounties this week, won none, and still told myself next week is the one.

The line works because it is a real week, not a template: a concrete detail — 25 bounties built, none won — that could only be this week. It carries the win (25 shipped) and the fail (zero won) in one breath, and the sharp turn is the last clause, the delusional optimism of already believing next week is the one. Self-deprecating, relatable, and fresh — every word earns its place inside the 100-character limit.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
